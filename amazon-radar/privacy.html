Amazon Radar プライバシーポリシー

対象: Amazon Radarの個人用Gmail比較機能。運営者: YoheiUmeda。

取得と目的

利用者が同意したGoogleアカウントの https://www.googleapis.com/auth/gmail.readonly 権限を使用します。この権限はメール全体を読める範囲を持ちますが、通常の比較処理ではKeepa通知を対象とする検索条件でメッセージを選び、有限のページ・件数だけを処理します。選択したメールのヘッダー/認証情報、本文、Gmail受信時刻を解析し、送信元の確認と商品・価格・通知時刻の比較に使用します。認可時の同一アカウント確認にはアカウント識別情報を使用します。

メールの送信・削除・変更は行いません。読み取ったGmailデータを広告、信用評価、汎用AIモデルの開発・学習には使用しません。メール本文を外部AIへ自動送信する機能はありません。

保存

OAuth tokenは所有者端末の非公開ファイルとして保存します。比較に必要なASIN、価格種別、価格・閾値、受信時刻、メッセージ識別子のハッシュ、アカウント識別子のハッシュ、処理継続情報、比較結果をローカルの比較state/証跡に保存します。ハッシュを保存していても、個人情報との関連が完全に失われた匿名情報とは断定しません。

現在の自動比較はメール原文を解析時に使用し、通常の比較stateには原文全体を保存しません。形式や信頼性を確認できないメッセージは、受信時刻・識別子ハッシュ・理由などを隔離記録に残します。所有者が別途行う手動調査やエクスポートは、目的と対象を明示した管理の下で行います。

比較stateの明細は処理対象時刻を基準に約31日分を保持する設計です。backlogがある場合、実際の暦日では31日を超えることがあります。集計証跡・所有者が保全するバックアップは別に残ることがあり、すべての複製が31日で自動消去されるとは約束しません。所有者は必要がなくなったローカル記録とバックアップを削除できます。

外部への提供

比較機能はGoogle APIと通信してGmailを読み取り、ローカルのRadar記録と比較します。Gmailの本文や比較明細をこのGitHub Pagesにアップロードせず、GmailデータをDiscordへ自動転送する機能もありません。Radar本体のDiscord価格通知は別の処理です。Gmailデータの販売や広告目的の第三者提供は行いません。

この静的説明サイトはGitHub Pagesが配信します。GitHub側で取り扱う通信情報はGitHubのプライバシーに関する規約も参照してください。このページに独自のアクセス解析、広告、Googleログインは設けません。

アクセス停止と削除

所有者はGoogleアカウントの接続済みアプリ設定からAmazon Radarのアクセスを取り消せます。Google側のアクセス取消しは、既に保存されたローカルデータやバックアップを自動削除しません。所有者端末で比較処理とtoken/比較state/必要なバックアップを適切に削除して利用を終了します。

お問い合わせ: https://github.com/YoheiUmeda/task-system-personal/issues 。メール原文やtokenを公開issueに記載しないでください。個人用ツールのため、データ管理の主体は端末とアカウントの所有者本人です。

Amazon RadarによるGoogle APIから受信した情報の利用および他のアプリへの移転は、Limited Use要件を含むGoogle API Services User Data Policyに準拠します。
