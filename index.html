task-system personal

個人が自分のWindows PCだけで使うタスク整理ツールです。一般公開のサービスではなく、利用者は開発者本人1名に限られます。

できること

  • デスクトップのメモからタスクを読み取り、期限が近づくと本人のGmailアドレスへ通知メールを送る
  • メモとダウンロード済みPDFを、本人のGoogleドライブ内の指定フォルダへバックアップする

すべての処理は本人のPCで実行されます。外部サーバーはなく、データを第三者へ送ることはありません。

プライバシーポリシー

task-system personal is a single-user tool that runs only on its developer's own Windows PC. It reads task memos, sends reminder emails to the owner's own Gmail address, and backs up memos and downloaded PDFs to designated folders in the owner's own Google Drive. It is not offered to the public and has no server component. See the Privacy Policy.
